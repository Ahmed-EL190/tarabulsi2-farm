# نظام إدارة مزرعة آل الطرابلسي

React + Vite + Tailwind (RTL) + Firebase Auth/Firestore + Recharts + React Hook Form/Zod + ExcelJS.

## التشغيل
1. أنشئ مشروع Firebase؛ فعّل **Authentication (Email/Password)** و**Firestore**.
2. `cp .env.example .env` وأدخل مفاتيح تطبيق الويب (لا تضع أي مفتاح Admin/Service account في الواجهة).
3. `npm install` ثم `npm run dev`.
4. انشر القواعد والفهارس: `npx firebase-tools deploy --only firestore`.
5. افتح التطبيق ← «أول تشغيل؟ إعداد المدير الأول» لإنشاء أول مدير (يعمل مرة واحدة فقط بحماية القواعد). بعدها أنشئ المستخدمين من صفحة «المستخدمون والصلاحيات».
6. (اختياري) ضع صورة المزرعة في `public/banner.jpg` لتظهر خلف ترويسة الرئيسية.

## الأوامر
`npm test` (27 اختبار محاسبي وصلاحيات) · `npm run build` · `npx firebase-tools deploy` (Hosting: `dist`).

## الأدوار
admin (كل شيء + اعتماد التسويات) · accountant (إضافة/تعديل/إلغاء) · data_entry (إضافة فقط) · viewer (قراءة). تُفرض في `firestore.rules`.

## البنية
`src/lib/finance.js` منطق مالي نقي ومُختبر · `src/data/ops.js` عمليات متعددة السجلات في دفعة ذرية · `src/pages/*` الصفحات · `docs/ANALYSIS.md` تحليل ملف Excel والافتراضات.

## الحالة الحالية (صادقة)
**منفّذ ومُختبر آلياً (منطق):** اتفاقيات الحليب/تسليمات/دفعات مقدمة/توزيع FIFO/رصيد دائن/استرداد، كشف حساب العميل، قروض الشركاء (أصل مقابل فائدة)، دفتر الشريك، مصروف بمصدر شريك دون تكرار، مصروفات تشغيلية مقابل غير تشغيلية، الصندوق متعدد العملات والتحويلات، الأرباح والخسائر، تخصيص الأرباح مقابل التوزيع النقدي، القطيع والتبادل ومنع تكرار الرقم، الصلاحيات.
**منفّذ وبُني (`vite build` ناجح) لكن لم يُجرَّب على مشروع Firebase حي:** كل الصفحات الـ17، لوحة الرئيسية، التقارير (18 تقريراً) وتصدير Excel/PDF، القواعد.
**غير منفّذ / للمرحلة التالية:** مرفقات Firebase Storage؛ اختبارات قواعد Firestore بالمحاكي؛ اختبارات واجهة (E2E)؛ ترجمة إنجليزية؛ قيود الفترات المغلقة؛ إدارة الموردين كسجلات مستقلة (حالياً اسم نصي)؛ فهارس مركّبة (لا حاجة لها بالاستعلامات الحالية)؛ تقسيم الحزمة (حجمها كبير 2.2MB).
PDF يتم عبر نافذة طباعة مهيأة (حفظ كـ PDF) للحفاظ على سلامة الحروف العربية.
